
# BURGER HOUSE Oruro

## Proyecto final

Desarrollo de una tienda virtual multipágina utilizando HTML5, CSS3, JavaScript y JSON.

## Objetivo

Desarrollar una tienda virtual que permita mostrar productos gastronómicos, administrar visualmente un catálogo y presentar estadísticas de inventario.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- JSON
- localStorage
- fetch()

## Estructura del proyecto

- index.html: página principal.
- productos.html: catálogo de productos.
- nosotros.html: información del emprendimiento.
- contacto.html: formulario de contacto.
- dashboard.html: panel de estadísticas.
- carrito.html: carrito de compras.
- faq.html: preguntas frecuentes.
- data/productos.json: información de los productos.
- css/estilos.css: diseño de la tienda.
- app/: archivos JavaScript.
- img/: imágenes del proyecto.

## Funcionalidades

- Catálogo de 15 productos.
- Búsqueda de productos.
- Filtros por categorías.
- Ordenamiento por precio.
- Control de disponibilidad.
- Dashboard estadístico.
- Formulario validado.
- Carrito con localStorage.
- Diseño adaptable.

## Ejecución

Abrir la carpeta en Visual Studio Code y ejecutar index.html mediante Live Server.
